# Boogey Features

The boogey features is based on the boogeyman from Last Life. It will select a random or set amount of player to be boogey for that session. When a player is boogey they typically lose all aliances, they must kill one non-red player before the end of the session or they will lose all lives but one. Going to their last life.

## How to enable
You can run the roll boogey command `/watcher boogey roll` near the start of the session. You could also enable it to start right when the session does with [autostart](/feature/autostart). The [boogey command](/usage/commands/boogey) has a few helpful commands for managing them.
