# session.conf

- `sessionLength` (Default: `180`) : How many minutes a default or automatically started session will last (can override when starting the session with commands).
- `breakLength` (Default: `10`) : How long the break will be when automatically started or with the command.
- `startSessionTimer` (Default: `false`) : Should the timer be started when the server is, but pauses right away to not actually start.
