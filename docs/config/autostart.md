# `autostart.conf`

The first session is triggered with the [`/watcher session first`](/usage/commands/session) before the session timer has started.

- `rollLives` (Default: `false`) : Should lives be rolled between 2 and 6 on the very first session.
- `rollBoogeys` (Default: `false`) : Should boogeymen be rolled with the default max at the start of every session.
- `rollSoeulmates` (Default: `false`) : Should soulmates be rolled at the start of the first session.
