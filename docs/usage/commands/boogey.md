# `/watcher boogey`

- `roll`: Rolls between 1 and [maxBoogeymen](/config/boogey) boogeymen, with the specified chance.
- `roll <MAX>`: Rolls between 1 and `MAX` boogeymen, still the with same chance.
- `cure <TARGET>`: Cures `TARGET` of the boogey curse.
- `fail <TARGET>`: Fails `TARGET` with the boogey curse.
- `failall`: Fails every currently uncured boogey.
- `reset`: Removes the boogeyman curse from everyone without failing or curing.
